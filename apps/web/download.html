Install a Linux package

AppImage

chmod +x Noburi_0.1.0_amd64.AppImage
./Noburi_0.1.0_amd64.AppImage

.deb

sudo apt install ./Noburi_0.1.0_amd64.deb

Alpha builds are not signed yet. Check each file against the SHA-256 listed on its release page.

Build from source

Any system with Node 22, pnpm and the Tauri prerequisites. 

git clone https://github.com/jiordiviera/noburi
cd noburi
pnpm install
pnpm desktop
