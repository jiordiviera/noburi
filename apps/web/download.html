Before you start
  • Claude Code, installed and signed in. Your agents run on it.
  • GitHub CLI, signed in with gh auth login, for the issue board.
  • Git. Node is not needed to run the packaged app: it ships inside.
Install a Linux package

AppImage

chmod +x Noburi_0.1.0_amd64.AppImage
./Noburi_0.1.0_amd64.AppImage

.deb

sudo apt install ./Noburi_0.1.0_amd64.deb

Alpha builds are not signed yet. Download SHA256SUMS next to the file and check it: 

sha256sum -c SHA256SUMS --ignore-missing

Build from source

Any system with Node 22, pnpm and the Tauri prerequisites. 

git clone https://github.com/useburoo/noburi
cd noburi
pnpm install
pnpm desktop
